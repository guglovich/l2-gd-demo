# The L2 client AUDIO inventory — 20_18 (Dark Elf Village) stage prep

Generated by `tools/l2strict/audio_catalog.py` (the raw machine catalog:
`tmp/audio/catalog.json`, regenerable). Sources are READ-ONLY at
`/Games/ElmoreX3` — nothing is copied into the repo yet.

## Formats (verified byte-level)

| Source | Format | Extraction |
|---|---|---|
| `Sounds/*.uax` (29 packages) | UE2 audio packages, `Lineage2Ver111` header + XOR 0xAC body (same crypto as the maps); Sound exports = UE2 Sound objects with **PCM WAV** (22050 Hz mono 16-bit) payloads after a ~9-byte UE header (`RIFF` scan ≤ 64 B) | `crypto.decrypt` + `l2_probe.Package`; RIFF scan proven on 9 samples (ffprobe: 22050/1) |
| `music/*.ogg` (277 tracks) | `L2SD` container: magic(4) "L2SD" + ver(4)=2 + zero(4) + size(4) + zero(4) + hash(4) = **28 bytes**, then the RAW 30-byte vorbis identification packet, then ogg pages with **mangled page headers** (the capture/fields zeroed — a plain OggS-scan does NOT produce a playable stream; NT_DarkElf = 44100 Hz stereo confirmed from the ID packet) | needs a dedicated L2SD reverse pass (re-derive the page headers) — queued |
| `Voice/` (50 files) | plain ogg + `systemmsg_e.uax` | direct |
| `system/musicinfo.dat`, `system/skillsoundgrp.dat` | `Lineage2Ver413` (l2enc RSA scheme) | **BLOCKED** — needs the l2encdec embedded RSA key (public in the l2encdec sources); the next-session step |

Total: **~5900 sounds / ~610 MB** across 29 .uax packages + 277 music
tracks + 50 voice files.

## Sorted by the user's categories

### 1. Background music — `music/` (277 L2SD-ogg tracks)

Layered naming: `*_F` = the full mix, `*_S01/_S02` = the stem layers;
`BS*_A/D` = battle themes (A/D variants); `CT_*` = race creation themes
(`CT_DarkElf` = the Dark Elf one); `B/D/F/...` families = the location
themes (the exact 20_18 assignment needs musicinfo.dat — the blocker
above).

### 2. Footsteps — `stepsound.uax` (93 WAVs)

Ground types × walk/run (3 samples each):
`default, grass, stone, Stone_Hard, gravel, carpet, dirt,
water_shalow` — everything the village needs (grass fields, stone
roads, the tunnel gravel/dirt, carpet interiors). The character-race
footstep variants additionally live in `chrsound.uax` (`STONE/BOW/SWIM/
WATER/SNOW/DIRT/GRAVEL` prefixes — the race-specific step/armor sets).

### 3. Items — `itemsound.uax` (330) + `ItemSound2.uax` (65) + `ItemSound3.uax` (33)

`armor_metal_*` (31), `itemdrop_weapon/armor/etc`, `itemequip_*`,
`public_sword/armor`, `sword_great`, `shield_steel` — equip/drop/armor
sounds; `ItemSound2`: `castle_door/wall`, `wooddoor_open`,
`stonedoor_creak`, memorial/firework sets (the door/interaction
material sounds).

### 4. Interaction/UI — `InterfaceSound.uax` (11), `EtcSound.uax` (6), `MessengerSound.uax` (4), `chrsound2.uax` (40)

`click, inventory_open/close, map_open/close, charstat_open/close,
system_open/close, sc_shot`; `elcroki_song, battle`; NPC voices
(`npc_old/youngf/oldf/doctor/public`), `fishing_splash/swish/linepull`.

### 5. Dark Elf character voices — `chrsound.uax` (1029) + `chrsound2.uax`

Per race-gender voice sets of 53 sounds. The Dark Elf set = **122
entries**:
- `FDELF_*` (female): `Death, Breath_1/2, Standup, Sitdown, Victory,
  Greeting, Followme, 1H_Atk, 1H_S_Atk, 2H_S_Atk, Pole_Atk, ...`
- `MDELF_*` (male): the same set.
The other race sets (`F/M` × `ELF/DELF/HUMAN(H)/ORC(O)/DWARF(D)` ×
`FIGHTER/MAGICIAN`, NPC `FNPC/MNPC` — 36 each) — for the village NPCs.

### 6. Skills (the professions) — `SkillSound*.uax` ×10 (556 WAVs)

The sound names ARE the skill names: `flame_strike, wind_strike,
aqua_swirl, aura_burn, drain_energy, curse_poison, disrupt_undead,
bind_will, power_shot, critical_hit` (the starter/profession skills —
including the Dark Elf mystic strikes), `crystal_carol, lightning_strike,
hydro_blast, dance_of_*, fatal_cast, antaras_breath, baium_*` ...
**DECODED (2026-11-19):** `skillsoundgrp.dat` decrypts with
`wine l2encdec.exe -d <full dat>` (the -s pair worked only for
musicinfo). 1398 groups = [skill sounds][per-race voice variants]:
**335 groups carry the `chrsound.m/f_darkelf_*` variants = the skills
the Dark Elf classes cast** (68 unique sounds: wind_strike,
flame_strike, aura_burn, drain_energy, curse_poison, vampiric_touch,
sleep, heal, recharge, death_whisper, focus_sonic, hate, might,
empower, poison_cloud, ice_bolt, wind_walk, mortal_blow, ...). The
full list: `tmp/audio/de_skills.txt`. The per-race variants are the
character VOICE lines layered over each skill cast
(`chrsound.m_darkelf_sub/call/white/notarget/throw`).

### 7. Monsters — `MonSound*.uax` ×10 (3246 WAVs, ~290 MB)

Per-monster voice/attack sets (the prefix survey is in catalog.json) —
the 20_18 mobs (orcs, spiders, wolves, the Imps...) get filtered when
the spawn list enters the stage.
